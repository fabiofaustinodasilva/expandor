# GeoSales CRM

# Documento 29

# Guia de Desenvolvimento com Cursor AI

Versão: 1.0

Status: Oficial

---

# 1. Objetivo

Este documento define como utilizar o Cursor AI para desenvolver o GeoSales CRM.

O objetivo é garantir:

- Desenvolvimento organizado.
- Código padronizado.
- Evolução segura.
- Menos erros.
- Respeito à arquitetura.

---

# 2. Papel do Cursor AI

O Cursor será utilizado como:

- Desenvolvedor assistente.
- Analista de código.
- Criador de arquivos.
- Revisor técnico.
- Auxiliar de testes.

---

# 3. Regra Principal

Antes de criar qualquer código:

A IA deve ler:

```
/docs
```

e entender:

- Regras de negócio.
- Arquitetura.
- Banco de dados.
- Padrões.

---

# 4. Nunca começar pelo código

Fluxo correto:

Entender requisito.

↓

Planejar solução.

↓

Apresentar arquivos que serão criados.

↓

Aguardar aprovação.

↓

Criar código.

---

# 5. Primeiro Comando no Cursor

Utilizar:

```
Leia todos os documentos existentes na pasta /docs.

Você é responsável pelo desenvolvimento do GeoSales CRM.

Não crie código ainda.

Primeiro apresente:

1. Arquitetura entendida.

2. Estrutura do projeto.

3. Plano inicial de desenvolvimento.

Aguarde aprovação.
```
