# Sprint 8.1.4 — Premium Admin Experience

## Objetivo

Elevar a UX/UI do painel administrativo ao padrão SaaS internacional — **sem** novos módulos, regras de negócio, banco, auth ou permissões.

## Entregas

1. Design System ampliado (`rc-ux-polish`): page-header, breadcrumb, metric-card, filter-bar, alerts warning/info, modal, tabelas hover
2. Componentes: `<x-ux.page-header>`, `<x-ux.metric>`, empty-state e modal refinados
3. Sidebar Platform mais limpa (largura, padding, hover, ativo)
4. Dashboard Platform reorganizado com hierarquia e métricas padronizadas
5. Empresas + Site público com cabeçalho e breadcrumb padronizados
6. Filtros de empresas em português (valores de filtro preservados)
