# UX checklist (manual)

- [ ] Produto: selecionar Valor fixo → campo R$
- [ ] Produto: selecionar Porcentagem → campo %
- [ ] Preview atualiza com preço do produto
- [ ] Contratar com fixed → toast comissão correta
- [ ] Contratar com % → comissão = % × line_total
- [ ] Comissão 0 → sem som de moeda
- [ ] Comissão > 0 → som + “VENDA FECHADA!”
- [ ] Reload após venda → sem novo som
- [ ] Editar produto % → venda antiga intacta
- [ ] Nova venda usa nova %
- [ ] Mobile web: toast não bloqueia mapa
