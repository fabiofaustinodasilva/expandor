# Academia Corporativa

Versão: 1.0

Status: Oficial

---

# 1. Objetivo

Este documento define o funcionamento do módulo Academia Corporativa do GeoSales CRM.

A Academia será responsável por centralizar treinamentos, materiais e conhecimentos necessários para capacitação das equipes comerciais.

---

# 2. Conceito

A Academia Corporativa transforma conhecimento da empresa em uma base organizada de treinamento.

O objetivo é permitir que qualquer vendedor tenha acesso rápido às informações necessárias para realizar uma venda com mais qualidade.

---

# 3. Objetivos do Módulo

Permitir:

- Treinar novos vendedores.
- Padronizar abordagens.
- Reduzir dúvidas em campo.
- Melhorar conversão.
- Centralizar informações.
- Medir evolução dos colaboradores.
