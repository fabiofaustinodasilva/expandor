# GeoSales CRM

# Documento 27

# Plano de Desenvolvimento MVP

Versão: 1.0

Status: Oficial

---

# 1. Objetivo

Este documento define o plano de desenvolvimento da primeira versão funcional do GeoSales CRM.

O MVP deverá entregar uma solução real para equipes comerciais externas.

---

# 2. Objetivo Principal do MVP

Criar uma plataforma onde uma empresa consiga:

- Cadastrar vendedores.
- Criar campanhas.
- Registrar visitas porta a porta.
- Cadastrar clientes.
- Visualizar clientes no mapa.
- Controlar retornos.
- Acompanhar resultados.

---

# 3. Regra do MVP

Não desenvolver inicialmente:

- Recursos complexos de IA.
- Aplicativo completo.
- Marketplace.
- Integrações avançadas.

Primeiro validar o processo comercial.

---

# 4. Usuários do MVP

Teremos inicialmente:

---

## Administrador

---
