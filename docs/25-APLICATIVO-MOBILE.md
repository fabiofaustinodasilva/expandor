# GeoSales CRM

# Documento 25

# Aplicativo Mobile

Versão: 1.0

Status: Oficial

---

# 1. Objetivo

Este documento define o funcionamento do aplicativo mobile do GeoSales CRM.

O aplicativo será utilizado principalmente por vendedores e supervisores em campo.

Objetivos:

- Facilitar vendas porta a porta.
- Registrar clientes rapidamente.
- Trabalhar com localização.
- Aumentar produtividade.
- Permitir operação offline.

---
