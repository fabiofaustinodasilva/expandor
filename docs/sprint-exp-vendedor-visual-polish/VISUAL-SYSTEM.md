# VISUAL SYSTEM — EXP Vendedor

## Cores
- Azul: navegação, info, status de ponto.
- Laranja: ação comercial (produtos, aba ativa, chips de vencimento).
- Verde: sucesso / comissão paga.
- Vermelho: erro, logout, exclusão.
- Slate: metadados.

## Tipografia
- Título de tela: `.pane-title`
- Nome: `.card__title`
- KPI: `.stat-card__value` / `.stat-card--hero`
- Meta: `.card__meta`

## Toque
`--touch: 48px` em botões, GPS, busca, nav.

## Motion
150–250ms existentes; `prefers-reduced-motion` desliga pin/deck transition.

## Componentes
Botão primário / ghost / accent / success / danger; badges pending / approved / paid; sheets com handle + footer + safe-area; empty-state texto curto.
