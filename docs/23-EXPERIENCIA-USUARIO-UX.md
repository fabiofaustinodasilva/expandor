# GeoSales CRM

# Documento 23

# Experiência do Usuário (UX/UI)

Versão: 1.0

Status: Oficial

---

# 1. Objetivo

Este documento define os princípios de experiência do usuário do GeoSales CRM.

O objetivo é criar uma plataforma:

- Fácil de usar.
- Rápida.
- Intuitiva.
- Adaptada para vendedores externos.
- Profissional para gestores.

---

# 2. Público Principal

O sistema possui quatro usuários principais:

---

# Vendedor

Usuário em campo.

Necessidades:

Registrar cliente rapidamente.

Ver próximos retornos.

Consultar treinamentos.

Usar mapa.

---

# Supervisor

Responsável pela equipe.

Necessidades:

Acompanhar vendedores.

Ver produtividade.

Cobrar resultados.

---

# Gestor

Responsável comercial.

Necessidades:

Analisar dados.

Tomar decisões.

Criar estratégias.

---

# Administrador

Responsável pela empresa.

Necessidades:

Configuração.

Usuários.

Permissões.

---
