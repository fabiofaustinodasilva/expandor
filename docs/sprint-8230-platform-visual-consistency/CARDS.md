# CARDS

## Padrões

| Tipo | Componente / classe | Uso |
|------|---------------------|-----|
| Card | `.card` (layout) | Superfície genérica |
| Section | `x-client.section-card` | Bloco com título |
| Metric | `x-client.metric-card` | Dashboard / KPIs |
| Interactive | `.card` + link/CTA | Integrações, equipe |
| Status | badge dentro do card | situação, presença |

Não transformar tudo em card. Nested cards (estoque em Produtos) permaneceram — refactor estrutural seria ruído.

Mapa: cards Tailwind do day brief e sheets **não** foram convertidos.
