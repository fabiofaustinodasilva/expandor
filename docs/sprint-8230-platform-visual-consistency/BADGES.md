# BADGES

## Tons compartilhados

| Tone | Classe | Uso |
|------|--------|-----|
| success | `.badge-success` | pago, ativo, sucesso |
| warning | `.badge-warning` | pendente, estoque baixo |
| danger | `.badge-danger` | erro, bloqueado |
| info | `.badge-info` (novo alias) | informativo |
| primary | `.badge-primary` | destaque operacional |
| neutral | `.badge` | default |

Componente: `x-client.status-badge` agora aceita `info`.
