# Sprint 8.2.30 — Design system + consistência visual

Sprint de **consistência, polimento, padronização e responsividade**.  
Não é redesign. Não altera regra de negócio.

## Resultado

O mesmo Expandor, agora com linguagem visual compartilhada entre Seller, Manager, Administrator e Super Admin:

- tokens CSS alinhados ao ThemeService;
- page headers, empty states, badges, botões e tabelas reutilizados;
- páginas de erro 403/404/419/500 com branding;
- glossário UX (Ponto / Cliente / Visita) aplicado onde era seguro.
