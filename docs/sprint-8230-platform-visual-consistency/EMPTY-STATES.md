# EMPTY STATES

Padrão: `x-client.empty-state` — ícone Lucide, título, descrição curta, CTA opcional. Sem modal bloqueante.

## Aplicado

| Tela | Título | CTA |
|------|--------|-----|
| Produtos | Nenhum produto cadastrado | Cadastrar produto |
| Minhas visitas | Você ainda não registrou visitas | Ir para o mapa |
| Agenda (hoje) | Nenhum retorno hoje | Ver todos |
| Agenda | Nenhum retorno na agenda | Ir ao mapa |
| Comissões | Nenhuma comissão no período | — |

Copy de comissões preserva a string assertada pelos testes (`Nenhuma comissão no período`).
