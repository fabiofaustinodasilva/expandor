# VISITS-AUDIT

## Como visita nasce

1. FirstApproach (create property+visit)  
2. Map visit em ponto existente (`map.visits.store`)  
3. Sales App visit (status/notes/GPS — sem cart completo)  

## Histórico no imóvel

Drawer do mapa mostra dados do ponto + última interação parcial.  
Agenda mostra follow-ups.  
`operations.my-visits` / visit show existem para quem tem permissão.

## Resposta

> O vendedor consegue saber rapidamente o que aconteceu anteriormente naquele imóvel?

**Parcialmente.** No mapa, o drawer resume endereço/status/contato; não há timeline completa “uma mão” no drawer. Para histórico rico, precisa sair do fluxo de rua (clientes/visits).

## Glossário

Visita ≠ Ponto ≠ Cliente — UI mistura rótulos (ver ISSUES).
