# AGENDA-AUDIT

## O que existe

1. **Agenda** (rail) — `follow-ups.index` — retornos pendentes + completar  
2. **Day brief** no mapa — visitas / interessados / contratos do dia  
3. **Sales App Retornos** — lista paralela  
4. Dashboard “Resultado” — métricas período  

## Resposta

> O vendedor sabe o que precisa fazer hoje ao abrir o sistema?

**Parcialmente.** Abre no **mapa** (bom) com brief (métricas agregadas), mas **não** vê automaticamente a lista “retornos de hoje às 18h”. Precisa ir em Agenda.

## Oportunidade P0/P1

Home operacional = Mapa + faixa “Hoje: N retornos” clicável → Agenda filtrada.
